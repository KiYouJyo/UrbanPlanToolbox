# Security Policy

[简体中文](SECURITY.md) | [日本語](SECURITY.ja.md)

## Supported versions

Only the latest formal release receives security-fix support. Older versions may not receive fixes; upgrade to the latest release before confirming that a report still applies.

## Reporting a vulnerability

Please do not report an unpatched security vulnerability through a public Issue. Contact the maintainers through GitHub's private security-reporting channel.

Please include, where possible:

- A description and potential impact
- The affected version, installation channel, and Windows version
- Reproduction steps or a minimal example
- Relevant logs or screenshots, after removing personal data, local paths, and credentials

The maintainers will assess the scope, remediation, and disclosure timing after confirmation. Do not include passwords, tokens, private keys, or other secrets in a report.
