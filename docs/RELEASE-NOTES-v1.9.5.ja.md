# UrbanPlanToolbox v1.9.5 インスピレーションレコーダーのウィジェット

- Windows 11のインスピレーションレコーダーは大サイズのみ。名称と分類を横並びにし、本文は複数行入力に対応します。
- 前へ・次へ・新規・削除・保存の5つの操作を踏襲し、履歴選択メニューと読み込みボタンを廃止します。
- 既存の記録・プロジェクト・バックアップ形式を維持し、プロセス間の同時保存を保護します。本文入力欄の高さにはWindowsのウィジェットホスト側の制約があります。
