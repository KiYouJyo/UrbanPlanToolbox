# UrbanPlanToolbox v1.8.5 Settings, About, and window-state refinement

- Lets Settings and About cards span the available content width while preserving the existing page margins, card material, inner controls, and responsive behavior.
- Fixes the inactive-window mismatch between the title bar and left navigation surface: active windows keep the dark/light teal surfaces, while inactive windows consistently switch to dark/light gray.
- Limits this update to Settings, About, and window-state presentation without changing update management, WebDAV, navigation logic, or other existing functionality.
