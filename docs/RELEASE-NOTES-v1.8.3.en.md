# UrbanPlanToolbox v1.8.3 update management UI and display fixes

- Fixes Available version and What's new disappearing when Microsoft Store reports an update before trusted target-version metadata is resolved. Unknown values remain visible as placeholders while stale or incorrect target-version metadata continues to be suppressed.
- Redesigns About > Update management with a more compact version comparison, release-notes, and status layout. On narrower windows, the content automatically stacks vertically to reduce horizontal space usage.
- Shows a single ProgressRing inside the update action button while checking for updates, removing duplicate loading-state indicators.
- Fixes the release-notes scrollbar overlapping text by reserving safe spacing inside the scroll area.
