# UrbanPlanToolbox v1.8.5 設定・バージョン情報・ウィンドウ状態の調整

- 設定画面とバージョン情報画面のカードを利用可能なコンテンツ幅いっぱいに広げつつ、既存のページ余白、カードの質感、内部コントロール、レスポンシブ配置を維持しました。
- ウィンドウが非アクティブになった際にタイトルバーと左ナビゲーション領域の色が一致しない問題を修正しました。アクティブ時は濃い青緑／淡い青緑を維持し、非アクティブ時は濃い灰色／淡い灰色へ統一して切り替わります。
- 今回は設定、バージョン情報、ウィンドウ状態の表示調整に限定し、更新管理、WebDAV、ナビゲーションロジック、そのほか既存機能は変更していません。
