UrbanPlanToolbox

面向城乡规划、建筑设计与空间研究的现代 Windows 工具箱。把项目工作台、规划资料库、GIS/调研辅助、灵感记录与数据备份集中到一个离线优先的 WinUI 3 应用中。

都市・地域計画、建築設計、空間研究のためのモダンな Windows ツールボックス。プロジェクト、専門データ、GIS・調査支援、アイデア記録、バックアップをオフライン優先の WinUI 3 アプリに統合します。

A modern Windows toolbox for urban planning, architectural design, and spatial research—bringing project workspaces, professional references, GIS/survey helpers, idea capture, and backup into one offline-first WinUI 3 app.

围绕规划与设计工作流构建計画・設計ワークフローのためにBuilt around planning and design workflows

不是单一计算器，而是一组可以独立使用、又共享项目与数据基础的专业工具。

単一の計算機ではなく、独立して使えながらプロジェクトとデータ基盤を共有する専門ツール群です。

Not a single calculator, but a set of focused professional tools that can work independently while sharing a common project and data foundation.

项目工作台プロジェクトProject workspace

v1.9.2 将三套专业资料库接入独立的 UrbanPlanToolbox_Data 数据仓库。应用可主动检查官方 Catalog、下载新的 .uptdata，也支持本地导入和回退到上一版本。所有数据包在激活前都会进行 ID、Schema、最低应用版本、路径安全、大小与 SHA-256 完整性校验。

v1.9.2 では3つの専門ライブラリを独立した UrbanPlanToolbox_Data に接続しました。公式 Catalog の確認、.uptdata の取得、ローカル読み込み、前版へのロールバックに対応し、有効化前に ID、Schema、最低アプリ版、パス安全性、サイズ、SHA-256 を検証します。

v1.9.2 connects all three professional libraries to the independent UrbanPlanToolbox_Data repository. The app can explicitly check the official catalog, download .uptdata packs, import local packs, and roll back to a prior version. Pack ID, schema, minimum app version, path safety, size, and SHA-256 integrity are validated before activation.

数据更新仅由用户主动触发；断网时已安装数据包仍可离线使用。

データ更新はユーザー操作時のみ行われ、オフラインでもインストール済みデータを利用できます。

Data updates are user-triggered; installed packs remain available offline.
