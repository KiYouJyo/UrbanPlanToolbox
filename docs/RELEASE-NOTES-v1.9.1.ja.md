# UrbanPlanToolbox v1.9.1 安定性とプロジェクトワークスペース保守

- 1.9.1 のバージョン情報、三言語リリースノート、署名受け入れ、二系統公開ガバナンスを整理しました。
- 設計プロジェクトのワークスペースを保守し、概要では「重点戦略」を表示し、戦略を1件ずつ編集できるようにしました。研究プロジェクトから「結果チャート」と「データ／スクリプト」カードを削除しました。
- レイアウト更新のフィードバックループにより、プロジェクトを開く際にフリーズまたはアプリ終了が発生する可能性がある問題を修正し、回帰チェックを強化しました。
- 重点戦略カードはカード幅に合わせて自動で折り返し、内容がカードの高さを超える場合は縦スクロールできます。
- プライバシーポリシーと第三者通知を整形済み Markdown として表示し、Markdown のソース記号を直接表示しないようにしました。
- プロジェクト Schema 3、バックアップ形式 2、既存の更新機構は変更しません。
- 完全な CI と Signed Acceptance の検証後、本バージョンを GitHub Releases と Microsoft Store の両方へ公開することを承認しました。
