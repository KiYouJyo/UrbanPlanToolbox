# UrbanPlanToolbox v1.9.1 エンジニアリング・クローズアウトとバージョン管理

- アプリ、アセンブリ、GitHub／Store Manifest、候補リリースメタデータ、project-status SSOT のバージョンを統一し、1.9.0 のビルド状態と古い 1.8.5 の文書状態が併存する不整合を解消します。
- CI の文書整合性チェックを強化し、project-status の製品版／候補パッケージ版が `release/release.json`、プロジェクトファイル、両 Manifest と一致することを必須化します。今後のバージョン情報のずれはマージ前に検出されます。
- 1.9.0 固定だった署名受け入れフローを、現在のリリースメタデータからバージョンを取得する汎用フローへ変更し、今後の保守版ごとのワークフロー複製を不要にします。
- 1.8.1～1.9.0 の CHANGELOG 履歴を補完し、1.9.1 の三言語および構造化ランタイム向けリリースノートを追加します。
- プロジェクト Schema、バックアップ形式、更新機構、ユーザー向け機能は変更しません。1.9.1 は現在、検証待ち候補であり、GitHub Release の自動作成や Microsoft Store への自動送信は行いません。
