# UrbanPlanToolbox v1.8.0 バックグラウンド動作とインスピレーションレコーダー

- バックグラウンド常駐とシステムトレイに対応し、メインウィンドウを閉じた後もツールボックスを動作させ続けられます。
- インスピレーションレコーダーを追加し、デザインや研究のアイデアをすばやく記録して、インスピレーション管理ページで整理できます。
- Windows サインイン時のサイレント起動と、レコーダーの自動表示オプションを追加しました。どちらも初期状態は OFF です。
- 初回起動ガイドに、レコーダーの紹介と設定ページを追加しました。
- レコーダーは最前面表示と右上配置に対応し、タスクバーと Alt+Tab には表示しません。
- レコーダーのレイアウト、ライト/ダークテーマ、タイトルバーボタン、中国語・日本語入力の操作性を改善しました。
- メインウィンドウの初回表示を DPI に応じた大きさにし、画面中央に配置するようにしました。
