# 灵感记录器与后台驻留

v1.8.0 为 UrbanPlanToolbox 增加了桌面驻留能力和独立的灵感记录器。它的目标是让应用在不打断当前工作的情况下，快速记录设计或研究想法。

## 灵感记录器

灵感记录器拥有独立的本地存储，不要求先创建项目。

当前能力包括：

- 持久化 Draft 草稿
- 快速记录新灵感
- 历史记录导航
- `Design` / `Research` 分类
- 编辑与删除
- 可选地关联兼容项目
- 在设计 / 研究工具页中以分类卡片查看灵感

项目关联是可选的。灵感本身不是项目正文的附属临时字段，因此即使没有项目，也可以独立记录和管理。

## 后台驻留

应用可使用 Windows 通知区域作为后台入口，并支持 Close-to-Tray 生命周期。

典型行为是：

1. 用户开启后台驻留相关设置；
2. 主窗口关闭后，应用可以继续驻留；
3. 从通知区域入口重新打开主窗口或快速记录灵感；
4. 当主窗口正常显示在任务栏时，通知区域图标可隐藏；
5. 主窗口再次回到后台驻留状态后，通知区域入口恢复。

这些行为由用户设置控制，不是应用强制常驻。

## 登录后启动

UrbanPlanToolbox 提供由用户控制的 Windows 登录后后台启动任务。是否启用应根据个人使用习惯决定：

- 经常需要快速记录想法：可以开启；
- 只偶尔使用工具箱：保持关闭即可。

后台启动不改变“离线优先”原则，也不意味着应用自动上传项目或灵感。

## 卸载与更新

v1.8.1 处理了后台驻留进程可能阻塞正常 MSIX 卸载的问题：当当前包正在被移除时，驻留进程会退出。

应用更新时也需要遵循各自发行渠道的更新流程。若遇到更新或卸载异常，先确认所有 UrbanPlanToolbox 窗口和驻留实例均已退出，再参考 [故障排除](Troubleshooting.md)。

## 灵感与项目工作台

v1.9.0 的项目磁贴工作台可以包含灵感相关磁贴。这里要区分两层：

- **灵感存储**：独立、本地、可单独存在；
- **项目呈现**：可以在兼容项目中显示或关联相关灵感。

因此删除项目不应被理解为自动删除所有独立灵感记录；具体删除行为以应用实际确认提示为准。

## 隐私

灵感文本属于用户业务数据。应用的存储诊断原则要求日志不得记录完整用户文本、项目内容、附件内容、密钥或证书。

如果使用 `.uptbackup` 或 WebDAV 云归档，请同时阅读 [数据、备份与隐私](Data-Backup-and-Privacy.md)。
