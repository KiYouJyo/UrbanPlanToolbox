# 专业知识库与 Data Pack

UrbanPlanToolbox 将规划与建筑专业资料作为“可独立更新的数据”，而不是把全部内容永久写死在应用版本里。

从 v1.9.2 起，三套专业知识库统一采用独立 **Data Pack** 架构：

1. 建筑 / 规划法规索引
2. 中日英规划术语库
3. 设计理念库

运行时数据来自独立仓库 **`KiYouJyo/UrbanPlanToolbox_Data`** 发布的数据包，而不是继续依赖应用仓库中的旧快照。

## 为什么要把数据和应用分开

专业资料的更新频率与程序代码不同。独立 Data Pack 可以做到：

- 不升级应用也能更新资料内容；
- 应用和数据拥有独立版本号；
- 已安装数据包可离线使用；
- 更新失败时不破坏当前有效版本；
- 保留旧的有效版本用于回滚；
- 对每个来源和数据版本进行更清晰的追踪。

## Data Pack 能做什么

当前架构包含官方目录解析、版本选择、下载安装、本地 `.uptdata` 导入、已安装版本解析与回滚。

激活数据包前会检查：

- Data Pack 身份
- schema
- 最低应用版本
- 路径安全
- 清单声明的文件大小
- SHA-256
- 未声明 payload
- 路径穿越风险

只有通过验证的数据才会成为活动版本。

## 更新策略

Data Pack 的更新检查是**用户主动触发**的。安装后的数据包保存在本机，因此离线时仍能使用当前有效版本。

这与应用更新完全独立：

| 项目 | 应用更新 | Data Pack 更新 |
| --- | --- | --- |
| 更新对象 | WinUI 3 应用、功能与代码 | 法规、术语、设计理念等专业数据 |
| 版本号 | 例如 `1.9.3` | 例如 `2026.08.3` |
| 更新入口 | GitHub / Microsoft Store | Data Pack 官方目录 / 本地 `.uptdata` |
| 离线可用 | 已安装应用可用 | 已安装数据包可用 |
| 回滚 | 依发行渠道处理 | 保留有效旧包用于回滚 |

## 法规索引

法规库用于快速检索建筑与规划相关法规条目，并通过搜索列表与详情面板查看结构化信息。

资料库的职责是**索引和辅助查找**，不应被视为替代官方法规发布平台或法律意见。涉及项目合规、报批或法律效力时，应回到条目注明的官方来源核对最新正式文本。

## 规划术语库

术语库面向中文、日语和英语的规划专业表达。v1.9.2 的 Data Pack 1.0 基线包含 140 条三语规划术语；后续内容以活动数据包为准。

术语库适合：

- 中日英术语对照
- 留学 / 研究写作中的专业表达确认
- 跨语言规划制度比较
- 从中文、日语或英语关键词检索概念

术语翻译属于专业资料，不等同于普通机器翻译；如用于正式论文或法规引用，仍应核查对应语境与来源。

## 设计理念库

设计理念库用于整理可复用的规划 / 建筑设计概念、分类、适用项目类型、标签、案例说明与来源说明。

v1.9.3 对该数据包进行了较大扩展：

- Data Pack 版本升级到 `2026.08.3`；
- 从 68 条扩展到 **109 条**经审阅的规范化理念；
- 补齐中、日、英三语的分类、适用项目类型、标签、案例说明和来源说明；
- 搜索支持三种语言的分类、项目类型和标签；
- 中文规范化筛选键继续作为兼容键保留。

设计理念库应当记录“项目明确表达的理念”，而不是根据作品图面主观猜测不存在的命名。

## 版本与来源

专业资料页应优先展示活动 Data Pack 的版本和来源信息。Wiki 不维护一份平行的“当前条目总数”作为永久事实；版本更新后，应以活动 Data Pack 和对应 Release 为准。
