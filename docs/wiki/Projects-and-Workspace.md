# 项目与工作台

项目系统用于整理设计与研究任务，但不会把独立工具强制绑定到某个项目。你可以完全不创建项目而直接使用计算、坐标或资料库工具；需要长期组织资料时，再使用项目工作台。

## 两类项目

### 设计项目

稳定类别为 `design`。适合课程设计、竞赛、科研型设计、专业项目、个人项目等。设计项目拥有自己的设计资料字段，并可使用面向设计流程的工作台磁贴。

### 研究项目

稳定类别为 `research`。适合课程研究、论文、研究项目等。研究项目包含研究领域、研究对象和研究方法等专属资料，并提供研究框架、问题、结果、文献、数据 / 脚本、进度等工作台内容。

> `ProjectKind` 在创建后不可更改。显示语言、项目名称或项目类型标签变化都不会改变项目的稳定 ID 与目录。

## 项目主页

项目主页在设计项目与研究项目之间切换，并只显示对应类别的未归档项目。项目列表按最近更新时间组织；归档页则统一显示两类已归档项目。

常见操作包括：

- 新建设计 / 研究项目
- 编辑项目基本信息
- 打开项目工作台
- 设置重要时间节点
- 选择工作文件夹
- 归档项目
- 从归档中恢复项目

归档项目为只读状态，恢复后重新可编辑。

## 可自定义磁贴工作台

v1.9.0 将项目页重构为“固定项目概览 + 项目级自定义磁贴工作台”。

工作台采用规范的 **12 列布局**，支持：

- 添加磁贴
- 移动
- 调整尺寸
- 复制
- 移除
- 撤销
- 重置布局

在较窄窗口中，界面可按 8 / 6 / 单列响应式呈现；这种显示变化不会覆盖项目保存的规范布局。

设计与研究项目可使用不同的专属磁贴，例如：

- 图片
- 重要时间节点
- 灵感
- 文件
- 策略
- 研究框架
- 研究问题
- 研究结果
- 文献
- 数据 / 脚本
- 进度

具体可用磁贴取决于项目类别和当前版本。

## 工作文件夹

项目可以通过 Windows `FolderPicker` 关联一个工作文件夹。应用保存的是 Windows 授权 token、显示名称和参考路径，而不是把整个外部文件夹复制进应用数据目录。

UrbanPlanToolbox 不会因为关联了工作文件夹就自动：

- 扫描整个目录
- 监视文件变化
- 修改文件内容
- 把外部工作文件夹装进 `.uptbackup`

工作文件夹授权 token 也不能跨电脑迁移。导入备份后，项目会保留必要的显示信息，但需要用户重新选择文件夹以恢复授权。

## 项目数据如何保存

每个项目使用不可变 GUID，典型结构为：

```text
data/projects/index.json
data/projects/<project-guid>/project.json
attachments/projects/<project-guid>/
backups/projects/<project-guid>/project.json.last-valid.bak
```

当前项目 schema 为 **3**。项目正文通过统一 JSON 存储层进行原子写入、版本检查、迁移和损坏恢复；单个项目损坏不应阻止其他项目被读取。

## 归档与删除的区别

**归档**只改变项目状态与更新时间，不移动项目目录；它适合暂时从活动项目列表中隐藏已完成或暂停的项目。

永久删除是不同操作。底层保存逻辑使用暂存 / 回滚保护，避免项目索引与正文因为中途失败而进入不一致状态。

## 当前边界

根据现有项目合同，以下能力不应当被理解为已经实现：

- 设计项目与研究项目之间转换
- 多人实时协作
- 在线账户同步
- 自动备份外部工作文件夹全部内容
- AI 自动生成项目内容

项目未来可以与更多 GIS、调研与输出结果建立上下文关联，但应以实际发布版本为准。
