# 功能总览

UrbanPlanToolbox 的定位不是一个“大而全”的 GIS/CAD 替代品，而是一组面向规划、建筑与空间研究日常任务的轻量工具，并用项目系统、搜索、收藏和资料库把它们组织起来。

## 一级导航

当前 Shell 以以下入口为主：

- **项目**：设计项目与研究项目的创建、编辑、工作台、归档与恢复。
- **搜索**：按当前语言搜索工具，并管理收藏。
- **设计工具**：面向方案、调研和设计阶段的实用工具。
- **科研工具**：面向地理数据、研究准备和数据处理的工具。
- **归档**：查看已归档项目并恢复。
- **关于**：版本、更新和应用信息。
- **设置**：主题、语言、后台行为、提醒、数据管理与维护。

## 项目管理

项目分为两个稳定类别：

- `design`：设计项目
- `research`：研究项目

项目类别创建后不可转换。二者共享项目生命周期、时间节点和工作文件夹机制，但具有各自的专属资料字段和工作台卡片。

v1.9.0 起，项目页使用可自定义的磁贴工作台，采用 12 列规范布局，并支持添加、移动、缩放、复制、移除、撤销和重置。界面会针对较窄窗口响应式呈现，而不会覆盖保存的规范布局。

详见 [项目与工作台](Projects-and-Workspace.md)。

## 设计与规划工具

仓库当前公开说明包含以下代表性能力：

- 规划指标快速计算
- 单位与比例尺换算
- 色卡 / 配色方案
- 流程审核清单
- 建筑与规划法规索引
- 设计理念词典
- 调研照片整理
- EXIF / GPS 信息读取
- GIS 点位与 CSV 导出

这些工具保持相对独立；用户可以从分类页或搜索打开，不要求先创建项目。

## 科研与地理工具

当前公开功能包括：

- WGS 84、GCJ-02、BD-09 点坐标本地转换
- Shapefile 处理
- 调研照片与空间点位整理
- 面向研究过程的项目磁贴，例如研究框架、问题、结果、文献、数据 / 脚本与进度

UrbanPlanToolbox 当前路线仍强调“规划专用生产力工具”，而不是重做完整桌面 GIS。

## 专业知识库

v1.9.2 起，以下三套资料库统一转向独立 Data Pack 架构：

1. **建筑 / 规划法规索引**
2. **中日英规划术语库**
3. **设计理念库**

v1.9.3 的设计理念数据包已扩展到 109 条经过审阅的规范化理念，并补齐中、日、英元数据与跨语言搜索。

详见 [专业知识库与 Data Pack](Professional-Libraries.md)。

## 灵感记录器与后台驻留

v1.8.0 引入：

- Windows 通知区域入口
- Close-to-Tray 生命周期
- 用户控制的登录后后台启动
- 独立本地灵感存储
- 草稿持久化
- 快速记录器与历史导航
- Design / Research 分类
- 可选的兼容项目关联

详见 [灵感记录器与后台驻留](Inspiration-and-Background.md)。

## 数据与备份

本地业务数据使用明确的 schema、原子写入、最后有效备份和迁移机制。完整导出使用 `.uptbackup` 格式；v1.8.2 又在其上增加了 WebDAV **云归档**。

这里的“云归档”不是实时同步：本机仍是权威数据源，应用不会建立账户或自动进行多设备实时合并。

详见 [数据、备份与隐私](Data-Backup-and-Privacy.md)。

## 三语与主题

应用支持：

- 简体中文 `zh-CN`
- 日本語 `ja-JP`
- English `en-US`
- 浅色、深色与跟随系统主题

语言可在运行时切换。用户输入、项目资料和稳定 ID 不会因为界面语言变化而自动翻译或改写。

详见 [本地化与三语支持](Localization.md)。
