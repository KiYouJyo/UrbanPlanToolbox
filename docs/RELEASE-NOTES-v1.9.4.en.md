# UrbanPlanToolbox v1.9.4 Acrylic Backdrop and Navigation Cleanup

- Uses Acrylic exclusively for the main window and standalone Inspiration Recorder; Mica is no longer instantiated.
- Removes the background material selector and automatically normalizes saved legacy Mica preferences to Acrylic.
- Temporarily hides the unfinished database entry from primary navigation while retaining the database pages, data packs and services for later development.
- Retains light, dark and system themes without changing project data, backup format or existing updater behavior.
