# UrbanPlanToolbox v1.9.4 Mica and Acrylic Selection

- Adds instant Mica/Acrylic selection in Settings → Appearance and language.
- Persists the choice across restarts while keeping Mica as the default for existing installations.
- Applies the selected material to the main window and Inspiration Recorder alongside all theme modes.
- Adds trilingual text, compact layout, and regression tests without changing project, backup, or update mechanisms.
