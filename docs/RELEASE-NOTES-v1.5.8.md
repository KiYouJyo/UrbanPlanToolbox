# UrbanPlanToolbox v1.5.8

## 简体中文

UrbanPlanToolbox v1.5.8 正式发布。

- 恢复真实的更新下载进度条。
- 修复更新完成后应用无法自动重新启动的问题。
- 修复 GitHub 一键安装包的卸载脚本参数契约。
- GitHub 与 Microsoft Store 继续使用独立的下载和安装机制。

---

## 日本語

UrbanPlanToolbox v1.5.8 を正式にリリースしました。

- 更新ダウンロードの進行状況バーを復元しました。
- 更新完了後にアプリが自動再起動しない問題を修正しました。
- GitHub ワンクリックインストーラーのアンインストールスクリプトを修正しました。
- GitHub 版と Microsoft Store 版は独立した更新経路を引き続き使用します。

---

## English

UrbanPlanToolbox v1.5.8 is now available.

- Restored the update download progress bar.
- Fixed automatic restart after a completed update installation.
- Fixed the GitHub one-click installer uninstall script contract.
- GitHub and Microsoft Store continue to use independent download and installation pipelines.
