# UrbanPlanToolbox v1.8.0 Background Residency and Inspiration Recorder

- Adds background residency and system tray support, so the toolbox can keep running after the main window is closed.
- Adds the Inspiration Recorder for quickly capturing design and research ideas, with a full inspiration management page for organization.
- Adds silent Windows sign-in startup and automatic Recorder display options; both default to off.
- Adds a Recorder introduction and settings page to the first-run guide.
- The Recorder is always on top, positioned at the top right, and hidden from the taskbar and Alt+Tab switcher.
- Improves the Recorder layout, light/dark theme, title-bar buttons, and Chinese/Japanese input experience.
- Improves DPI-aware sizing and centered initial placement for the main window.
