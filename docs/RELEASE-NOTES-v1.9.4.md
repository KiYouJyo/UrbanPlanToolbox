# UrbanPlanToolbox v1.9.4 亚克力背景与导航整理

- 主窗口和独立灵感记录器统一采用亚克力背景，不再使用云母材质。
- 移除背景材质下拉设置；旧版保存的云母偏好将自动归一为亚克力，无需手动调整。
- 未完成的数据库模块暂时从主导航栏隐藏，保留数据库页面、数据包和服务代码，供后续继续开发。
- 保留浅色、深色和跟随系统主题；项目数据、备份格式及现有更新机制不变。
- 修复左侧导航栏被浅青色不透明填充覆盖的问题，让展开式导航直接显示亚克力窗口背景，并为高对比度模式保留系统背景。
