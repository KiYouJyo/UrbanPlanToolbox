# UrbanPlanToolbox v1.8.4 设置与关于页面现代化

- 现代化重构设置页除更新管理以外的卡片结构，沿用现有 WinUI 3 卡片背景、边框与主题资源，不改变原有整体质感。
- 按使用逻辑将设置页重新排序为“外观与语言 → 后台与启动 → 项目通知 → 数据管理 → 应用维护”，并为窄窗口补充自适应纵向布局。
- 重构关于页的应用信息、项目与开源、隐私与法律卡片，保留 v1.8.3 更新管理卡片样式，并移除诊断与日志卡片。
- 统一数据管理与 WebDAV 操作按钮为同一默认按钮视觉，不再混用强调色按钮；按钮文字也统一使用默认前景色。
