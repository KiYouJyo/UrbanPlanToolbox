# UrbanPlanToolbox v1.9.5 Inspiration Recorder Widget

- Create, browse and edit Design/Research inspirations in the Windows 11 widget, including title and content.
- Load history, save drafts, edit existing records and confirm deletion without opening the standalone recorder.
- Uses the same data as the desktop app with cross-process transaction protection; Windows 11 acceptance is pending.
