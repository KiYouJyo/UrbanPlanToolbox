# 行動規範

[简体中文](docs/community/CODE_OF_CONDUCT.md) | [English](docs/community/CODE_OF_CONDUCT.en.md)

## 私たちの約束

異なる背景や経験を尊重する、歓迎的で包摂的なコミュニティを維持します。

## 期待される行動

- 敬意を持って建設的にコミュニケーションする
- 個人を攻撃せず、問題と根拠に焦点を当てる
- 善意のフィードバックを受け入れ、意見が異なる場合も専門的に対応する
- プライバシー、データの境界、プロジェクトのローカル優先原則を尊重する

## 受け入れられない行動

ハラスメント、差別、脅迫、個人攻撃、個人情報の悪意ある公開、議論や貢献の意図的な妨害、その他コミュニティにふさわしくない行為は認められません。

## 適用

メンテナーは、この規範に違反する内容を編集、非表示、削除し、参加を制限または終了できます。対応が必要な行為は GitHub の非公開経路からメンテナーへ報告してください。セキュリティ脆弱性については[セキュリティポリシー](SECURITY.ja.md)に従ってください。
