# UrbanPlanToolbox ロードマップ

現在の製品・配布チャネルの事実は [project-status.json](project-status.json) が唯一の基準です。変更履歴は [CHANGELOG.md](../CHANGELOG.md) と版別リリースノートに記録します。

## 現在の段階

UrbanPlanToolbox は 1.x の安定化・製品化段階にあります。v1.6.8 は新しい専門ツールを追加しない保守の収束版です。GitHub updater は検証済みかつ凍結、Microsoft Store updater の最終 E2E は保留です。

## 優先事項

1. 三言語ドキュメント、リリース情報、ローカライズの契約を維持する。
2. 実測した起動時間、パッケージサイズ、依存関係の基準値を維持する。
3. Store の実際の配信による N → 1.6.8 E2E の後にのみ Store updater を凍結する。

将来の作業に未承認のバージョン番号や日付は割り当てません。
