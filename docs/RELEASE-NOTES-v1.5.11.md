## 简体中文

- 修复 GitHub 侧载版点击下载并安装后跳转浏览器的问题。
- GitHub 更新现在由应用内直接下载并校验 MSIXBundle。
- 下载并校验完成后，由 Windows 包部署机制直接完成本地 MSIXBundle 更新。

## 日本語

- GitHub 版でダウンロードしてインストールを選択した際にブラウザーへ遷移する問題を修正しました。
- GitHub 更新で MSIXBundle をアプリ内から直接ダウンロードして検証するようにしました。
- ダウンロードと検証の完了後、Windows のパッケージ展開機能を使用してローカル MSIXBundle を直接更新します。

## English

- Fixed GitHub updates opening the browser when Download and install is selected.
- GitHub updates now download and verify the MSIXBundle directly inside the app.
- After download and verification, the local MSIXBundle is updated directly through Windows package deployment.
