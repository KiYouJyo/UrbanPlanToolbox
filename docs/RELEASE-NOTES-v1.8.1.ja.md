# UrbanPlanToolbox v1.8.1 バックグラウンド常駐、トレイメニュー、プロジェクト画面の修正

- バックグラウンド常駐プロセスが MSIX のアンインストールを妨げる場合がある問題を修正し、現在のアプリパッケージのアンインストール開始時に常駐プロセスが終了するようにしました。
- システムトレイの右クリックメニューをコンパクトな WinUI 3 スタイルのポップアップに変更しました。メイン画面とインスピレーションレコーダーの両方が非表示でもメニューを開けるようにし、Windows の隠れているインジケーターのパネルにメニューが隠れる問題も修正しました。
- メインの UrbanPlanToolbox ウィンドウがタスクバーに表示されている間は通知領域アイコンを非表示にし、メインウィンドウを閉じてバックグラウンド常駐へ戻るとトレイアイコンを自動的に復元します。
- Microsoft Store で更新を検出してダウンロードする前に、前のバージョン番号や前の更新内容が表示される場合がある問題を修正しました。現在のバージョンより新しい信頼できる対象バージョンのみを表示し、その対象と一致する更新内容だけを表示します。
- デザインプロジェクト画面を簡素化し、行政区と緯度・経度を非表示にし、プロジェクト説明を基本情報へ統合、計画要件カードを削除し、保存とリセットをページ下部へ移動しました。
- 研究プロジェクトでも保存とリセットをページ下部へ移動しました。
- 非表示になった旧デザインプロジェクト項目のデータ互換性は維持され、既存の行政区、緯度・経度、計画要件は保存時に失われません。
