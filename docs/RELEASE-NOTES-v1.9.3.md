# UrbanPlanToolbox v1.9.3 设计理念数据库第三版

- 设计理念数据库升级至第三版数据包 2026.08.3：在已审核的 68 条基础上新增 41 条 canonical 理念，共 109 条。
- 彻底补齐设计理念词典的中日英三语支持：分类、适用项目类型、标签、案例备注和来源说明现在都会随应用语言切换，不再在日文或英文界面回退显示中文。
- 新增数据包级三语标签目录，在保持现有中文 canonical 键与筛选兼容性的同时，为界面提供完整的本地化显示值。
- 旧版数据包仍可读取；当日文或英文翻译缺失时不再错误显示中文案例，更新至 2026.08.3 后可获得完整内容。
- 搜索现在同时覆盖三语分类、项目类型与标签，切换语言后仍可用当前语言检索设计理念。
