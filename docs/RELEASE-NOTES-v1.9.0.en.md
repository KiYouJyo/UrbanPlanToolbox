# UrbanPlanToolbox v1.9.0 Customizable tile project workspace

- Redesigns both design- and research-project pages around a fixed project overview plus a project-scoped customizable tile workspace, replacing the dense always-visible form layout.
- Adds a canonical 12-column project layout with add, move, resize, duplicate, remove, undo, and reset operations. Removing a panel or resetting the layout never deletes the underlying project text, files, inspirations, or milestones.
- Design projects can use image showcase, milestones, project notes, linked inspirations, files, and key-strategy panels; research projects can use research framework, core question, results chart, literature, data/scripts, and research-progress panels.
- Adds responsive workspace presentation: full-width windows keep the 12-column free layout, medium widths reflow to 8 or 6 columns, and narrow windows use a single-column reading view. Responsive reflow affects presentation only and never overwrites the saved 12-column layout.
- Moves project-overview editing, milestone management, work-folder actions, and panel settings into focused dialogs or a right-side drawer. Archived projects remain read-only, while older projects automatically receive and persist a compatible workspace layout when first opened.
