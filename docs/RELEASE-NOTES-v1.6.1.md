## 简体中文

UrbanPlanToolbox v1.6.1 改进 GitHub 侧载渠道的更新流程。

- 改进 GitHub 更新包下载完成后的状态管理。
- 新增下载并验证完成后的“重启并更新”操作，由用户主动触发更新。
- 改进更新失败时的状态保护，避免安装流程尚未交给 Windows 就退出应用。
- 本版本仅通过 GitHub Releases 发布，不提交 Microsoft Store。

## 日本語

UrbanPlanToolbox v1.6.1 は GitHub サイドロード版の更新フローを改善します。

- GitHub 更新パッケージのダウンロード完了後の状態管理を改善しました。
- ダウンロードと検証が完了した後に、ユーザーが実行する「再起動して更新」操作を追加しました。
- Windows にインストール処理が引き渡される前にアプリが終了しないよう、失敗時の状態処理を改善しました。
- 本バージョンは GitHub Releases のみで公開し、Microsoft Store には提出しません。

## English

UrbanPlanToolbox v1.6.1 improves the GitHub sideload update flow.

- Improved state handling after a GitHub update package finishes downloading.
- Added a user-triggered “Restart and update” action after the package is downloaded and verified.
- Improved failure handling so the app does not exit before Windows has accepted the installation request.
- This release is distributed through GitHub Releases only and is not submitted to Microsoft Store.
