# UrbanPlanToolbox v1.8.1 后台卸载、托盘菜单与项目页精简

- 修复后台驻留进程可能阻止 MSIX 正常卸载的问题；卸载当前应用包时，驻留进程会主动退出。
- 将系统托盘右键菜单改为紧凑的 WinUI 3 风格弹窗，并保留打开工具箱、灵感记录器、设置和退出等原有操作。
- 精简设计项目页面：隐藏行政区与经纬度字段，将项目说明并入基本信息，移除规划要求卡片，并把保存与重置操作移动到页面底部。
- 研究项目的保存与重置操作同样移动到页面底部。
- 已隐藏的旧设计项目字段仍保留底层数据兼容性，保存旧项目时不会清空既有行政区、经纬度或规划要求数据。
