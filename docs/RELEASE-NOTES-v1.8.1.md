# UrbanPlanToolbox v1.8.1 后台驻留、托盘菜单与项目页修复

- 修复后台驻留进程可能阻止 MSIX 正常卸载的问题；卸载当前应用包时，驻留进程会主动退出。
- 将系统托盘右键菜单改为紧凑的 WinUI 3 风格弹窗；即使主界面和灵感记录器都已隐藏，仍可从纯后台驻留状态正常打开菜单，并修复菜单被 Windows 隐藏图标面板遮挡的问题。
- 主工具箱窗口显示在任务栏时自动隐藏通知区域图标；关闭主窗口回到后台驻留后，托盘图标自动恢复。
- 修复 Microsoft Store 检测到更新但尚未下载时可能显示上一版本号和上一版本更新内容的问题；现在只显示严格高于当前版本的可信目标版本，并只展示与该目标版本匹配的更新说明。
- 精简设计项目页面：隐藏行政区与经纬度字段，将项目说明并入基本信息，移除规划要求卡片，并把保存与重置操作移动到页面底部。
- 研究项目的保存与重置操作同样移动到页面底部。
- 已隐藏的旧设计项目字段仍保留底层数据兼容性，保存旧项目时不会清空既有行政区、经纬度或规划要求数据。
