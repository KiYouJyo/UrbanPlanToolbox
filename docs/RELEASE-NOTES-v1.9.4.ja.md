# UrbanPlanToolbox v1.9.4 アクリル背景とナビゲーション整理

- メインウィンドウと独立したインスピレーションレコーダーの背景をアクリルに統一し、マイカの使用を停止しました。
- 背景素材の選択項目を非表示にし、旧設定のマイカ指定も自動的にアクリルへ正規化します。
- 開発途中のデータベースをメインナビゲーションから一時的に非表示にします。ページとデータパック、サービスの実装は保持します。
- ライト・ダーク・システムテーマに引き続き対応し、プロジェクト、バックアップ、更新機能との互換性を維持します。
