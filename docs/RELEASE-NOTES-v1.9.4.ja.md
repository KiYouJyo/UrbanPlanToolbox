# UrbanPlanToolbox v1.9.4 マイカ・アクリル切り替え

- 「設定 → 外観と言語」でマイカとアクリルを即時に切り替えられるようになりました。
- 選択は保存され再起動後も引き継がれます。既存設定の既定値はマイカです。
- メインウィンドウとインスピレーションレコーダーで同じ素材を使用し、すべてのテーマに対応します。
- 3言語UI、コンパクト表示、回帰テストを追加し、プロジェクト・バックアップ・更新機構を維持しました。
