# UrbanPlanToolbox v1.9.5 — Windows 11 灵感记录器小组件（大尺寸精简版）

## 外观与交互

- **仅提供 large（大尺寸）**；两个 MSIX 清单均不再声明 medium。
- 复刻原独立记录器 \`InspirationRecorderWindow.xaml\` 的结构：顶部记录序号、
  名称／分类并排（约 3:1）、详细信息多行输入、底部「‹」「›」「+」／「删除」「保存」。
- 不再显示历史下拉框、加载按钮、第二组标题、草稿专用按钮或额外确认页。
- 保存记录后保留当前记录；←/→ 在按创建时间升序的历史记录和草稿之间切换；
  「+」创建新草稿；「删除」直接删除当前已保存记录，与原记录器一致。
- 导航切换前会提交当前表单内容到现有灵感服务：已保存记录直接更新，
  草稿写入原有草稿字段；草稿通过「保存」转为正式记录。
- 三语标签；不启动桌面记录器。仍使用原 \`inspirations.json\`。
- 对大尺寸卡片设置 `minHeight: 410px`，把正文放入 `height: stretch` 容器，
  正文 `Input.Text` 本身也设为 `height: stretch`；让正文编辑框尽可能占据卡片剩余高度，
  并使底部操作栏贴近卡片下方。

## 技术限制

Windows Widgets Board 使用 **Adaptive Cards** 渲染控件，不能直接挂载原 WinUI 3
XAML。布局和按钮语义对齐，但具体拉伸是否生效仍由 Windows Widgets Board 宿主决定。
不是桌面窗口的逐像素复制。没有 TextChanged 回调，因此输入过程不能像原窗口那样
逐字自动保存草稿；按导航或「保存」才会写入。

## Windows 验收

1. 只显示 large 尺寸，小组件中没有 medium 选项。
2. 检查名称和分类的并排宽度、正文输入框以及底部五个按钮是否不被裁切；
   Windows 的 Adaptive Cards 宿主可能对 ActionSet 数量/位置另有限制。
3. 通过「‹」「›」按时间顺序浏览历史和草稿，「+」创建新草稿；
   编辑后切换应保存内容；删除应与原记录器保持一致。
4. 检查主程序同步、数据文件并发访问、三语、Windows 11 缩放比例。
5. 每次修改后重新构建签名验收包。通过系统宿主实测前不发布正式版。
