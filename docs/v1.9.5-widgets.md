# UrbanPlanToolbox v1.9.5 — 完整的 Windows 11 灵感记录器小组件（开发分支）

## 功能

- 在 Windows 11 的 Widgets Board（Win+W）中直接记录与管理灵感，**不依赖打开独立窗口**。
- 标题、正文、Design/Research 分类，可创建新灵感或保存原有独立草稿。
- 历史灵感选择下拉框（按时间取最近 50 条）、加载、编辑、保存。
- 删除分两步确认，直接删除原来的本地记录；取消/卸载小组件不会删除灵感。
- 使用原有 inspirations.json，主程序可继续读取、编辑这些记录。
- 中文、日文、英文；medium / large 大小。

## 技术架构

复用现有打包 WinUI 3 可执行文件，通过 COM --widget-provider 单独启动无窗口
IWidgetProvider 服务器，不启动 WinUI 主窗口，所有操作在 Widgets Board 内完成。
保存选中条目 ID 与删除确认状态到 WidgetUpdateRequestOptions.CustomState，以
保证宿主重启后仍能够恢复选择。每次操作由 Action.Execute 在
OnActionInvoked 里验证输入并写入 InspirationService；文件级跨进程
Semaphore 防止应用与小组件同时更新导致记录丢失。

此实现沿用 Adaptive Cards，并非原生 XAML 窗口，也不是桌面悬浮便签。
Adaptive Cards 在宿主中对文本输入、滚动和动作数量具有约束，发行前必须实机检验。
