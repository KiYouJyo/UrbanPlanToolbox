# UrbanPlanToolbox v1.9.5 — Windows 11 灵感记录器小组件（开发分支）

## 功能

- Windows 11 Widgets Board（Win+W）中的“灵感记录器 / Inspiration Recorder”。
- 显示最近的两条设计/科研灵感。
- 通过小组件的标题输入框与分类选择框快速保存；与原应用共用本地 inspirations.json。
- “打开记录器”启动原有 WinUI 3 独立记录器。
- 中文/日文/英文标签随应用语言设置回退到系统语言。
- 支持 medium / large 两种面板尺寸。暂不实现桌面常驻便签和网页小组件。

## 架构

复用现有 UrbanPlanToolbox.exe，通过 COM 参数 --widget-provider 启动无窗口服务模式；
不要经过 WinUI Application.Start 或单实例重定向。manifest 的两种发行身份
均注册相同的 IWidgetProvider CLSID 与 widget definition。

记录器复用 InspirationService。跨进程命名 Semaphore 使 read-modify-write
成为原子事务，避免桌面应用与 widget 同时保存时相互覆盖。
不修改历史灵感 JSON 数据模式、项目 schema 或备份 schema。

## Windows 验收清单（未在当前 Linux 执行环境完成）

1. dotnet test tests/UrbanPlanToolbox.Tests/UrbanPlanToolbox.Tests.csproj -c Release
2. 构建 GitHub 和 Store 两个发行渠道的 x64 MSIX，校验 package manifest schema。
3. 卸载旧版或从 1.9.4 升级至开发签名包；检查 COM 类与 widget provider extension 注册。
4. Win+W 添加灵感记录器，验证中、大尺寸页面、控件溢出、字体和主题。
5. 分类保存测试：在小组件创建，确认主程序管理页可见；反向在主程序保存，
   重新打开 Widgets Board 并确认近期记录更新。
6. 两进程同时保存多次，确认 inspirations.json 完整无丢项。
7. “打开记录器”在应用未启动、主窗口可见、主窗口已隐藏三种情形下正常工作。
8. 面板注销/解锁及系统重启后验证小组件恢复和更新；删除小组件不应删除灵感。
9. Windows Widget Board 如果不允许直接输入控件，在验收时调整为“打开记录器”入口，
   绝不能以未验证的体验向用户发布。
10. 对 Windows 10 或无 Widgets Board 的系统，主程序仍正常启动。
