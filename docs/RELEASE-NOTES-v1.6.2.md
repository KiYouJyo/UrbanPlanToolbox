## 简体中文

v1.6.2 修复 GitHub 侧载渠道更新管理卡片的稳定性问题：检查、下载和待安装状态会保留版本与 Release Notes 元数据，卡片字段保持稳定显示，加载动画不再脱离对应字段。

本版本仅面向 GitHub Release；未提交 Microsoft Store。

## 日本語

v1.6.2 は GitHub サイドロード版の更新管理カードを安定化します。確認、ダウンロード、インストール待ちの状態でもバージョンと Release Notes を保持し、カードの項目と読み込み表示を安定させます。

Microsoft Store には提出しません。

## English

UrbanPlanToolbox v1.6.2 stabilizes the GitHub sideload update-management card. Version and Release Notes metadata remain available during checking, downloading, and ReadyToInstall states, while the card fields and inline activity indicators stay structurally stable.

This release is GitHub-only and is not submitted to the Microsoft Store.
