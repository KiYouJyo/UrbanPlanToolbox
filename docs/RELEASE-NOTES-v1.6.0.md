# UrbanPlanToolbox v1.6.0

## 简体中文

- 项目主页的项目卡片新增工作文件夹快捷入口。
- 已绑定工作文件夹时可直接打开，未绑定时显示禁用状态。
- 优化项目卡片右侧更新时间与工作文件夹入口的布局。
- 修复 Microsoft Store 更新管理在当前已是最新版时显示无意义占位内容的问题。
- 统一 GitHub 与 Microsoft Store 更新状态的显示逻辑。

## 日本語

- プロジェクトホームのカードに作業フォルダーのショートカットを追加しました。
- 作業フォルダーを設定済みの場合は直接開くことができ、未設定の場合は無効状態で表示します。
- カード右側の更新日時と作業フォルダー入口のレイアウトを改善しました。
- Microsoft Store で最新バージョンを確認した際に不要なプレースホルダーが表示される問題を修正しました。
- GitHub と Microsoft Store の更新状態表示を統一しました。

## English

- Added a work-folder shortcut to project cards on the project home page.
- Bound folders can be opened directly; unbound folders remain visible as disabled actions.
- Improved the right-side layout for the update time and work-folder entry.
- Fixed meaningless placeholder content appearing after Microsoft Store reports that the app is up to date.
- Unified update-state presentation across GitHub and Microsoft Store channels.
