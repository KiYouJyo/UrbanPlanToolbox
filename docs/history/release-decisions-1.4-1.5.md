# Historical release decisions: 1.4–1.5

> Historical record. This file preserves prior release boundaries and exceptions; it is not the current release contract or Store policy.

Earlier release documentation recorded GitHub release decisions for v1.4.0 through v1.5.x, including separate Store submission exceptions, package acceptance gates, and the v1.5.8 local-update E2E gate. Those records established that GitHub and Store identities, packages, signing chains, and updates were separate, and that download completion could not replace deployment/restart evidence.

The former milestone-specific Store cadence and version-bound test targets are retained as historical decisions only. Current release and Store rules are defined by [RELEASE.md](../RELEASE.md), [STORE-PUBLISHING.md](../STORE-PUBLISHING.md), and [project-status.json](../project-status.json).
