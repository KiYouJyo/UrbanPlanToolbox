# UrbanPlanToolbox Privacy Policy / 隐私政策 / プライバシーポリシー

Last updated: 2026-08-02

## 简体中文

UrbanPlanToolbox 不要求账户，不收集、出售或上传个人信息。项目、设置、收藏、设计工具数据、通知相关时间节点和应用管理的附件保存在用户的本机。用户选择的外部工作文件夹只保存引用和操作系统访问令牌；应用不会复制或删除该文件夹。

用户可以在应用中导出、导入和清除本地数据。导出内容不包含日志、缓存、证书或密钥。通知只由 Windows 在本机调度。

应用不会自动联网。GitHub 侧载渠道只在用户主动检查更新时访问 GitHub Releases；Microsoft Store 渠道不调用 GitHub 更新服务。用户主动点击项目、Issue、法规或 Store 链接时，系统会打开对应的外部网站。应用没有遥测、广告、追踪器、自动崩溃上传或自动日志上传。

外部网站由其运营方负责，并适用各自的隐私政策。

## 日本語

UrbanPlanToolbox はアカウントを要求せず、個人情報を収集、販売、アップロードしません。プロジェクト、設定、お気に入り、設計ツールのデータ、通知に関係する予定、アプリが管理する添付ファイルはユーザーの PC に保存されます。ユーザーが選択した外部作業フォルダーについては参照情報と OS のアクセス トークンだけを保存し、そのフォルダーをコピーまたは削除しません。

ユーザーはアプリ内でローカルデータをエクスポート、インポート、消去できます。エクスポートにはログ、キャッシュ、証明書、鍵は含まれません。通知は Windows によって PC 上だけでスケジュールされます。

アプリは自動的にネットワークへ接続しません。GitHub 版はユーザーが更新確認を実行した場合だけ GitHub Releases にアクセスします。Microsoft Store 版は GitHub の更新サービスを呼び出しません。ユーザーがプロジェクト、Issue、法令または Store のリンクをクリックした場合だけ、システムが対応する外部サイトを開きます。テレメトリ、広告、トラッカー、自動クラッシュ送信、自動ログ送信はありません。

外部サイトには各運営者のプライバシーポリシーが適用されます。

## English

UrbanPlanToolbox requires no account and does not collect, sell, or upload personal information. Projects, settings, favorites, design-tool data, notification-related milestones, and app-managed attachments stay on the user’s device. A user-selected external work folder is retained only as a reference and operating-system access token; the app does not copy or delete that folder.

Users can export, import, and clear local data in the app. Exports do not contain logs, caches, certificates, or keys. Notifications are scheduled locally by Windows.

The app does not connect automatically. The GitHub side-load channel accesses GitHub Releases only when the user explicitly checks for updates; the Microsoft Store channel does not call the GitHub update service. When the user explicitly clicks a project, issue, regulation, or Store link, the system opens the corresponding external website. The app has no telemetry, advertising, trackers, automatic crash uploads, or automatic log uploads.

External websites are operated independently and have their own privacy policies.
