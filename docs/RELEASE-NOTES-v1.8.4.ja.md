# UrbanPlanToolbox v1.8.4 設定・バージョン情報画面のモダン化

- 更新管理以外の設定カードをモダン化し、既存の WinUI 3 カード背景・境界線・テーマリソースを維持して、アプリ本来の質感を変えないようにしました。
- 設定画面を「外観と言語 → バックグラウンドと起動 → プロジェクト通知 → データ管理 → アプリのメンテナンス」の順に整理し、狭いウィンドウでは自動的に縦配置へ切り替わるようにしました。
- バージョン情報画面のアプリ情報、プロジェクトとオープンソース、プライバシーと法的情報カードを再構成し、v1.8.3 の更新管理カードは維持したまま診断・ログカードを削除しました。
- データ管理と WebDAV の操作ボタンはすべて同じ標準ボタン外観と標準テキスト色に統一し、強調色ボタンの混在をなくしました。
