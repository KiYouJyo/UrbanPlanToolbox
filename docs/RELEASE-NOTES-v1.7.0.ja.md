# UrbanPlanToolbox v1.7.0 プラットフォーム基盤と更新セッションの凍結

- 更新の確認またはダウンロード中にページを切り替えると状態と進行状況が消える問題を修正し、更新タスクをアプリケーション セッション全体で維持します。
- 統一されたリリース メタデータ元を確立し、バージョン、更新内容、CHANGELOG、GitHub、Microsoft Store の公開情報の不整合を減らします。
- プロジェクト データ形式のバージョン、移行、後方互換性の規則を強化し、旧プロジェクトの長期的な読み取り可能性を高めます。
- パッケージ サイズと依存関係管理の決定的な baseline を確立します。
- GitHub と Microsoft Store の更新フローを安定化し、凍結の準備を完了します。
- 二つの配布チャネルの方針を整備し、GitHub を高頻度の安定リリース、Microsoft Store を主に安定したマイルストーン版に位置付けます。
