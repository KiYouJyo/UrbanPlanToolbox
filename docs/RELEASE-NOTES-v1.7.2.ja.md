# UrbanPlanToolbox v1.7.2 単一インスタンスと既存ウィンドウの呼び出し

- UrbanPlanToolbox は既定で単一インスタンスとして動作するようになりました。
- アプリが既に開いている場合、再起動すると既存のウィンドウを前面に表示し、2 つ目のツールボックスウィンドウは作成されません。
- 最小化されたメインウィンドウは、アプリを再度起動すると自動的に復元され、アクティブになります。
- Windows App SDK のアプリライフサイクルとアクティブ化のリダイレクトを強化し、Microsoft Store と GitHub の更新後再起動フローとの互換性を維持しました。
