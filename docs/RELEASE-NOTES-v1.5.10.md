## 简体中文

UrbanPlanToolbox v1.5.10 是一次更新管理界面修复版本。

- 修复当前已是最新版本时“可用版本”显示为不可用的问题。
- 修复当前已是最新版本时更新内容无法显示的问题。
- 优化尚未检查更新时的状态显示，改为显示“未检查”。

## 日本語

UrbanPlanToolbox v1.5.10 は更新管理 UI の修正版です。

- 最新バージョン使用時に利用可能バージョンが利用不可と表示される問題を修正しました。
- 最新バージョン使用時に更新内容が表示されない問題を修正しました。
- 更新確認前の状態を「未確認」と表示するよう改善しました。

## English

UrbanPlanToolbox v1.5.10 fixes the update management UI.

- Fixed the available version being shown as unavailable when the app is already up to date.
- Fixed release notes not being shown when the app is already up to date.
- Improved the pre-check state by showing “Not checked” instead of “Unavailable”.
