# UrbanPlanToolbox v1.8.3 更新管理界面与显示修复

- 修复 Microsoft Store 已检测到更新但目标版本元数据暂未解析时，“可用版本”和“更新内容”被隐藏的问题；未知值保持占位，同时继续避免显示陈旧或错误的目标版本信息。
- 重做“关于 > 更新管理”卡片，采用更紧凑的版本对比、更新内容和状态布局，并在较窄窗口自动切换为纵向排列，减少卡片横向占用。
- 检查更新时仅在操作按钮内显示一个 ProgressRing，移除重复的加载状态提示。
- 修复更新说明滚动条覆盖正文的问题，为滚动区域预留安全间距。
