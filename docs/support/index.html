在线隐私政策：Privacy。提交问题时请提供应用版本、安装渠道、Windows 版本、复现步骤、预期与实际结果。诊断信息分享前请移除项目内容、个人数据和不必要的本机路径。

問題を報告する際は、アプリのバージョン、インストール経路、Windows のバージョン、再現手順、期待結果と実際の結果を記載してください。診断情報からプロジェクト内容と個人情報を削除してください。

When reporting an issue, include the app version, installation channel, Windows version, reproduction steps, expected result, and actual result. Remove project content, personal data, and unnecessary local paths from diagnostics.
