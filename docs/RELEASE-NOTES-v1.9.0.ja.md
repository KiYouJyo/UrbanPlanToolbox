# UrbanPlanToolbox v1.9.0 自由配置タイル型プロジェクトワークスペース

- 設計プロジェクト／研究プロジェクト画面を全面的に再設計しました。上部には固定のプロジェクト概要を残し、その下をプロジェクトごとに自由配置できるタイル型ワークスペースへ変更し、密集した入力フォームによる視覚的負担を減らしました。
- プロジェクト単位の12列レイアウトを追加し、パネルの追加、移動、サイズ変更、複製、削除、取り消し、既定レイアウトへの復元に対応しました。パネルの削除やレイアウトのリセットで、本文・ファイル・アイデア・マイルストーンなど元データが削除されることはありません。
- 設計プロジェクトでは画像ショーケース、マイルストーン、プロジェクト説明、関連アイデア、ファイル、重点戦略などを、研究プロジェクトでは研究フレーム、中心研究課題、結果チャート、文献、データとスクリプト、研究進捗などを配置できます。
- レスポンシブ表示を追加しました。広いウィンドウでは12列の自由配置を維持し、中間幅では8列／6列へ自動変換、狭いウィンドウでは1列の閲覧表示に切り替わります。表示上の再配置は保存済み12列レイアウトを上書きしません。
- プロジェクト概要、マイルストーン、作業フォルダー、パネル設定は必要時だけ編集するダイアログ／右ドロワーへ整理しました。アーカイブ済みプロジェクトは引き続き読み取り専用で、旧プロジェクトは初回表示時に互換性のある新ワークスペースを自動生成・保存します。
