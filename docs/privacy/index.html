简体中文

UrbanPlanToolbox 不要求账户，不收集、出售或上传个人信息。项目、设置、收藏、工具数据、时间节点、通知数据和应用附件保存在本机。Microsoft Store 版更新由 Microsoft Store 管理；GitHub 旁加载版只有在用户主动检查更新时访问 GitHub Releases API。外部链接只在用户点击后打开。应用没有广告、遥测、追踪、自动崩溃上传或自动上传用户数据。

日本語

アカウントは不要で、個人情報を収集・販売・アップロードしません。プロジェクトやツールデータは端末に保存されます。Microsoft Store 版の更新は Store が管理し、GitHub サイドロード版が Releases API に接続するのは利用者が更新確認を実行した場合だけです。外部リンクはクリック時だけ開き、広告、テレメトリ、追跡、自動送信はありません。

English

UrbanPlanToolbox requires no account and does not collect, sell, or upload personal information. Projects and tool data are stored on the device. Microsoft Store updates are managed by Microsoft Store; the GitHub sideloaded build accesses the Releases API only when the user explicitly checks for updates. External links open only after a click. There are no ads, telemetry, tracking, automatic crash uploads, or automatic uploads of user data.
