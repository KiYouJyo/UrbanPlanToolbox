UrbanPlanToolbox Privacy Policy / 隐私政策 / プライバシーポリシー

Last updated / 更新日期 / 最終更新: 2026-08-02

简体中文

UrbanPlanToolbox 不要求账户，不收集、出售或上传个人信息。项目、设置、收藏、设计工具数据、通知相关时间节点和应用管理的附件保存在本机。用户可以导出、导入和清除本地数据。

应用不会自动联网。GitHub 侧载渠道只在用户主动检查更新时访问 GitHub Releases；Microsoft Store 渠道不调用 GitHub 更新服务。用户主动点击外部链接时，系统才会打开对应网站。应用没有遥测、广告、追踪器、自动崩溃上传或自动日志上传。

日本語

UrbanPlanToolbox はアカウントを要求せず、個人情報を収集、販売、アップロードしません。データは PC に保存され、ユーザーはローカルデータをエクスポート、インポート、消去できます。

アプリは自動接続しません。GitHub 版はユーザーが更新確認を実行した場合だけ GitHub Releases にアクセスし、Microsoft Store 版は GitHub 更新サービスを呼び出しません。外部リンクはユーザーがクリックした場合だけ開きます。テレメトリ、広告、トラッカー、自動クラッシュ送信、自動ログ送信はありません。

English

UrbanPlanToolbox requires no account and does not collect, sell, or upload personal information. Data stays on the user’s device, and users can export, import, and clear local data.

The app does not connect automatically. The GitHub side-load channel accesses GitHub Releases only when the user explicitly checks for updates; the Microsoft Store channel does not call GitHub updates. External links open only after the user clicks them. There is no telemetry, advertising, tracking, automatic crash upload, or automatic log upload.
