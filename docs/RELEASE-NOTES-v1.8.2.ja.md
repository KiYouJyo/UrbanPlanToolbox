# UrbanPlanToolbox v1.8.2 WebDAV クラウドアーカイブ

- 「設定 > データ管理」に WebDAV クラウドアーカイブを追加しました。ローカルデータは引き続き主データソースであり、ネットワークが利用できなくてもローカルのプロジェクトとツールは使用できます。
- 既存の `.uptbackup` 形式を再利用します。アップロード前にローカルでバックアップを生成・検証し、リモートでは一時ファイルへアップロードした後 `MOVE` で正式ファイルへ切り替え、中断したアップロードが正常なアーカイブに見えることを防ぎます。
- WebDAV 接続の設定・テスト、手動クラウド保存、履歴一覧、クラウドからの安全な復元、指定したリモートアーカイブの削除に対応しました。
- クラウド復元でも既存の manifest、SHA-256、形式バージョン検証、インポート前の安全バックアップと失敗時ロールバックを使用します。
- WebDAV パスワードは Windows Credential Locker に保存し、`settings.json`、`.uptbackup`、ログには書き込みません。HTTP 接続では HTTPS を推奨する警告を表示します。
- 「すべてのローカルデータを消去」はローカル WebDAV 設定と資格情報を削除しますが、リモートアーカイブは自動削除しません。
- 既存の「バックアップをエクスポート / インポート / すべてのローカルデータを消去」ボタンを横一列にし、データ管理カードの縦方向の占有を減らしました。
