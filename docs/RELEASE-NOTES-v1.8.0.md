# UrbanPlanToolbox v1.8.0 后台运行与灵感记录器

- 新增后台驻留与系统托盘支持，可在关闭主窗口后继续保持工具箱运行。
- 新增灵感记录器，可快速记录设计与科研灵感，并在完整灵感管理页面中继续整理。
- 新增 Windows 登录静默自启动与灵感记录器自动显示选项，两项默认均为关闭。
- 首次启动向导新增灵感记录器介绍与设置页面。
- 灵感记录器支持置顶、右上角定位，并从任务栏与 Alt+Tab 切换器中隐藏。
- 优化灵感记录器布局、深浅色主题、标题栏按钮与中日文输入法体验。
- 优化首次打开主窗口的 DPI 感知尺寸与居中定位。
