# UrbanPlanToolbox v1.7.0 平台底座与更新会话冻结

- 修复检查或下载更新时切换页面后状态和进度消失的问题；更新任务现在在整个应用会话内持续保留。
- 建立统一发布元数据源，减少版本、更新说明、CHANGELOG、GitHub 与 Microsoft Store 发布信息之间的不一致。
- 强化项目数据格式版本、迁移和向后兼容规则，提高旧项目长期可读取性。
- 建立包体积和依赖治理的确定性基线。
- 完成 GitHub 与 Microsoft Store 更新流程的稳定性收口和冻结准备。
- 完善双渠道发布策略，GitHub 作为高频稳定发布渠道，Microsoft Store 主要承载稳定里程碑版本。
