## 简体中文

UrbanPlanToolbox v1.6.7 主要修复应用图标和标题栏在浅色、深色主题下的显示一致性。

- 修复深色主题下标题栏应用图标对比度不足的问题。
- 修复浅色主题下最小化、最大化和关闭按钮识别困难的问题。
- 修复任务栏图标在浅色和深色 Windows 主题下出现反向配色的问题。
- 修复浅色开始菜单中应用图标仍使用白色前景的问题。
- 统一标题栏、任务栏和开始菜单图标的主题资源规则。
- 明确区分应用主题和 Windows Shell 主题，避免不同主题组合下出现错误图标。
- 完善黑白图标在不同 DPI 和资源尺寸下的一致性。

v1.6.7 已通过 GitHub Releases 发布，并已提交 Microsoft Store 认证。Microsoft Store 是否公开以实际认证和商店可用状态为准。

## 日本語

UrbanPlanToolbox v1.6.7 では、ライト / ダークテーマにおけるアプリアイコンとタイトルバーの表示一貫性を改善しました。

- ダークテーマでタイトルバーのアプリアイコンが見えにくい問題を修正しました。
- ライトテーマで最小化、最大化、閉じるボタンの視認性が低い問題を修正しました。
- Windows のライト / ダークテーマでタスクバーアイコンの配色が逆になる問題を修正しました。
- ライトテーマのスタートメニューで白いアイコンが表示される問題を修正しました。
- タイトルバー、タスクバー、スタートメニューのテーマ別アイコン規則を統一しました。
- アプリテーマと Windows Shell テーマを明確に分離しました。
- DPI とアイコンサイズごとの表示一貫性を改善しました。

v1.6.7 は GitHub Releases で公開され、Microsoft Store の認証に提出されています。Microsoft Store での公開は、実際の認証結果とストアでの利用可否を基準とします。

## English

UrbanPlanToolbox v1.6.7 improves icon and title-bar consistency across light and dark themes.

- Fixed low-contrast application icons in the title bar under dark theme.
- Fixed low-contrast minimize, maximize, and close buttons under light theme.
- Fixed reversed taskbar icon colors across light and dark Windows themes.
- Fixed the white application icon appearing in the light Start menu.
- Unified theme-aware icon rules across the title bar, taskbar, and Start menu.
- Clearly separated app-theme behavior from Windows Shell theme behavior.
- Improved icon consistency across DPI scales and resource sizes.

v1.6.7 is published through GitHub Releases and submitted for Microsoft Store certification. Microsoft Store publication is determined by the actual certification result and Store availability.
