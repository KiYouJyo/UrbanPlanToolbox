# 路线图与版本政策

## 最近开发完成版本

### v0.4.1 流程审核清单（随 v0.4.3 发布）

已实现离线流程审核清单及多分类工具接入：同一工具位于设计→前期分析和科研→前期工具，复用同一页面、数据目录和收藏状态；支持阶段、审核项、状态、重点项、备注、筛选、进度、复制、排序及通用备份导入导出。已随 v0.4.3 一并合并发布。

### v0.4.0 色卡方案记录器（详细设计，已发布）

v0.4.0 已通过 PR #17 合并并正式发布（tag `v0.4.0`）。该版本新增本地优先的色卡方案记录器，包含多图附件、多个独立颜色、颜色类型、HEX/RGB/ColorPicker 编辑、导入导出和三语响应式界面；同时作为后续新增工具的标准实现模板。

## 长期定位

UrbanPlanToolbox 将逐步发展为面向建筑设计、城乡规划和空间研究人员的模块化小工具平台。当前一级导航为：项目、搜索、设计工具、科研工具、项目归档、关于和设置；“关于”和“设置”固定在左侧导航底部。

设计工具的二级分类规划为前期分析、实地调研、方案推导、总体设计和详细设计；科研工具的二级分类规划为前期工具、地理工具和数据工具。“工具搜索”用于跨分类浏览和搜索已上线工具，并将收藏工具置顶；专业分类页面继续承担分类浏览。“项目归档”将记录用户的设计、规划及科研项目资料，例如名称、类型、地点、指导思想、说明和成果图片。

## 版本与发布政策

1. 所有 `v0.x.y` 均为预览版，包括 v0.3.0、v0.3.1 和 v0.9.9。预览属性必须在应用内版本显示、CHANGELOG、GitHub Release 说明以及其他面向用户的版本说明中明确标注。
2. 仅已决定公开发布的版本创建普通 GitHub Release，不使用 GitHub 的 Pre-release 标记。v0.3.4、v0.3.5 和 v0.3.8 是内部开发里程碑，不创建标签或 Release；v0.3.7 与 v0.3.9 已发布，当前公开候选为 v0.4.3。v1.0.0 前的公开版本共享同一条预览更新线，继续通过 `/releases/latest` 检查更新。
3. v1.0.0 是第一个正式版本，必须创建新的提交、`v1.0.0` 标签和 GitHub Release，重新构建正式发布资产，并在应用内显示“正式版”。不得仅修改旧 `v0.x` Release 或复用旧资产并将其称为正式版。
