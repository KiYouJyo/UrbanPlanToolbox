# 路线图与版本政策

## 当前定位

UrbanPlanToolbox 是面向城乡规划、建筑设计与空间研究的离线优先 Windows 工具箱。核心项目、工具数据和备份保存在本机，当前公开 Store 包面向 x64 Windows 用户。

## 当前版本

`0.5.0 Preview` 已发布至 Microsoft Store。Store 技术包版本为 `1.0.0.0`，仅用于包版本管理，不取代产品显示版本。当前已完成的模块包括项目与研究项目管理、工作台、归档恢复、时间节点提醒、工作文件夹入口、规划指标计算、单位与比例尺换算、色卡方案记录、流程审核清单、法规索引、设计理念词典、搜索收藏、本地备份恢复及三语界面。

## 已确认的未来方向

以下方向来自现有规划，尚未作为当前版本功能提供：

- 科研工具扩展，例如坐标系转换器和科研灵感整理器（评估中）。
- 项目管理模块的后续扩展（评估中）。
- 更多工具分类、数据源和工作流支持（评估中）。

路线图不擅自确定新的功能范围、版本号或发布日期；未标注为已完成的项目都不应被理解为已实现。

## 版本政策

- `0.x` 版本均为 Preview，产品显示版本、Release 说明和用户文档应保持一致。
- Microsoft Store 与 GitHub 旁加载渠道使用独立身份、包版本和更新流程。
- Store 包版本独立、单调递增，第四段为 `0`；产品显示版本继续表达用户可见的 `0.x Preview`。
- 只有实际准备公开的版本才创建 GitHub Release；内部里程碑不创建标签或 Release。

本文件说明方向，不构成对功能、版本或时间的承诺。
