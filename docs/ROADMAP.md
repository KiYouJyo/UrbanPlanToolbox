# 路线图与版本政策

## 长期定位

UrbanPlanToolbox 将逐步发展为面向建筑设计、城乡规划和空间研究人员的模块化小工具平台。当前一级导航为：项目、搜索、设计工具、科研工具、项目归档、关于和设置；“关于”和“设置”固定在左侧导航底部。

设计工具的二级分类规划为前期分析、实地调研、方案推导、总体设计和详细设计；科研工具的二级分类规划为前期工具、地理工具和数据工具。“工具搜索”用于跨分类浏览和搜索已上线工具，并将收藏工具置顶；专业分类页面继续承担分类浏览。“项目归档”将记录用户的设计、规划及科研项目资料，例如名称、类型、地点、指导思想、说明和成果图片。

## 版本路线图

已完成：

- v0.1.0：程序骨架和规划指标快速计算器。
- v0.1.1：安装方式优化。
- v0.2.0：单位与比例尺换算器。
- v0.3.0：检查更新和 GitHub 仓库入口。
- v0.3.1：接入现有应用图标并整理导航入口。
- v0.3.2：统一工具信息模型和工具注册基础。
- v0.3.3（已发布）：一级导航结构重构。

基础框架重构阶段：

- v0.3.4（内部开发里程碑，已完成）：二级分类、工具卡片和现有工具迁移。
- v0.3.5（内部开发里程碑，已完成）：收藏功能和常用功能页面。
- v0.3.6（已发布）：工具搜索、收藏置顶和拼音排序。
- v0.3.7（已发布）：三语支持与本地化基础（简体中文、日语、英语）。
- v0.3.8（内部开发里程碑，已完成但不单独发布）：本地业务数据存储、原子写入、恢复保护与逐版本迁移基础。
- v0.3.9（当前公开候选版本）：项目主页、项目工作台、待办、规划指标快照、工作文件夹入口、项目归档以及本地数据导入导出。

设计工具阶段：v0.4.0 色卡方案记录器（详细设计）、v0.4.1 法规档案馆（总体设计）、v0.4.2 设计灵感整理器（前期分析）、v0.4.3 调研结果记录（实地调研）、v0.4.4 设计理念词典（方案推导）。

科研工具阶段：v0.5.0 为科研工具阶段起始版本，范围待定；v0.5.1 坐标系转换器（地理工具）；v0.5.2 科研灵感整理器（前期工具）。

项目管理阶段：v0.6.x 为项目归档模块及相关扩展。v1.0.0 为 UrbanPlanToolbox 的第一个正式版本。

本路线图不代表当前版本已经实现后续功能。

## 版本与发布政策

1. 所有 `v0.x.y` 均为预览版，包括 v0.3.0、v0.3.1 和 v0.9.9。预览属性必须在应用内版本显示、CHANGELOG、GitHub Release 说明以及其他面向用户的版本说明中明确标注。
2. 仅已决定公开发布的版本创建普通 GitHub Release，不使用 GitHub 的 Pre-release 标记。v0.3.4、v0.3.5 和 v0.3.8 是内部开发里程碑，不创建标签或 Release；v0.3.7 已发布，v0.3.9 是当前公开候选。v1.0.0 前的公开版本共享同一条预览更新线，继续通过 `/releases/latest` 检查更新。
3. v1.0.0 是第一个正式版本，必须创建新的提交、`v1.0.0` 标签和 GitHub Release，重新构建正式发布资产，并在应用内显示“正式版”。不得仅修改旧 `v0.x` Release 或复用旧资产并将其称为正式版。
