# UrbanPlanToolbox v1.6.4

## 简体中文

UrbanPlanToolbox v1.6.4 主要改进响应式导航界面的视觉一致性。

- 统一大窗口常驻导航栏与小窗口覆盖式导航栏的背景视觉。
- 小窗口打开汉堡菜单后，左侧导航栏沿用与大窗口相同的导航背景样式。
- 保留 NavigationView 原有的响应式布局和覆盖式导航行为。
- 保持主窗口 Mica、导航项样式以及内容区域视觉不变。
- v1.6.4 同时作为 GitHub 侧载更新链路的下一真实验收目标。

本版本仅通过 GitHub Releases 发布，Microsoft Store 不在本次发布范围内。

## 日本語

UrbanPlanToolbox v1.6.4 は、レスポンシブ ナビゲーション インターフェイスの視覚的な一貫性を改善しました。

- 大きなウィンドウの常時表示ナビゲーションと小さなウィンドウのオーバーレイ ナビゲーションの背景表現を統一しました。
- 小さなウィンドウでハンバーガー メニューを開いた場合も、大きなウィンドウと同じナビゲーション背景スタイルを使用します。
- NavigationView の既存のレスポンシブ レイアウトとオーバーレイ動作を維持しています。
- メイン ウィンドウの Mica、ナビゲーション項目、コンテンツ領域の外観は変更していません。
- v1.6.4 は、GitHub サイドロード更新フローの次の実環境検証用ターゲットでもあります。

このバージョンは GitHub Releases のみで公開します。Microsoft Store は今回のリリース対象外です。

## English

UrbanPlanToolbox v1.6.4 improves visual consistency in the responsive navigation interface.

- Unified the background appearance of the persistent navigation pane in large windows and the overlay navigation pane in small windows.
- The navigation pane opened from the hamburger menu now uses the same visual background style as the large-window navigation pane.
- Preserved the existing responsive NavigationView layout and overlay behavior.
- Kept the main-window Mica backdrop, navigation-item styling, and content-area appearance unchanged.
- v1.6.4 also serves as the next real-world target for validating the improved GitHub sideload update flow.

This version is released through GitHub Releases only. Microsoft Store is not part of this release.
