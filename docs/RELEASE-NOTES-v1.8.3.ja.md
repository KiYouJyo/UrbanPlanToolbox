# UrbanPlanToolbox v1.8.3 更新管理画面と表示の修正

- Microsoft Store が更新を検出しても対象バージョンのメタデータが未解決の場合に、「利用可能バージョン」と「更新内容」が非表示になる問題を修正しました。未確定値はプレースホルダーのまま表示し、古いまたは誤った対象バージョン情報は引き続き表示しません。
- 「バージョン情報 > 更新管理」カードを再設計し、バージョン比較・更新内容・状態をよりコンパクトに配置しました。狭いウィンドウでは自動的に縦配置へ切り替わり、横方向の占有を抑えます。
- 更新確認中は操作ボタン内にのみ 1 つの ProgressRing を表示し、重複した読み込み状態表示をなくしました。
- 更新内容のスクロールバーが本文に重なる問題を修正し、スクロール領域に安全な余白を確保しました。
