# UrbanPlanToolbox v1.5.9

## 简体中文

UrbanPlanToolbox v1.5.9 正式发布。

- 修复 Release Notes 无法正确加载的问题。
- 修复更新目标版本显示错误的问题。
- GitHub 更新通过 Windows App Installer 官方界面进行。
- Microsoft Store 更新继续使用 Microsoft 官方更新界面。
- 移除 UrbanPlanToolbox 自定义的重复更新确认弹窗。
- 改进 About 的更新管理区域，显示当前版本、目标版本、更新状态和更新内容。

## 日本語

UrbanPlanToolbox v1.5.9 を正式にリリースしました。

- Release Notes が正しく読み込まれない問題を修正しました。
- 更新対象バージョンの表示を修正しました。
- GitHub 更新では Windows App Installer の公式 UI を使用します。
- Microsoft Store 更新では Microsoft の公式更新 UI を使用します。
- UrbanPlanToolbox 独自の重複する更新確認ダイアログを削除しました。
- About の更新管理領域を改善しました。

## English

UrbanPlanToolbox v1.5.9 is now available.

- Fixed Release Notes loading.
- Fixed incorrect target-version information in the update UI.
- GitHub updates now use the official Windows App Installer interface.
- Microsoft Store updates continue to use the official Microsoft update UI.
- Removed the duplicate UrbanPlanToolbox update confirmation dialog.
- Improved the About update management section.
