# UrbanPlanToolbox v1.9.1 稳定性与项目工作台维护

- 完成 1.9.1 版本事实源、三语发布说明、签名验收与双端发布治理收口。
- 维护设计项目工作台：项目概览使用“重点策略”信息，重点策略支持逐条维护；研究项目移除“结果图表”与“数据与脚本”卡片。
- 修复进入项目时可能因布局更新反馈循环导致卡死或闪退的问题，并加强相关回归检查。
- 重点策略卡片支持按卡片宽度自动换行，内容超过卡片高度时可纵向滚动。
- 隐私政策与第三方声明改为格式化 Markdown 展示，不再直接显示 Markdown 源标记。
- 保持项目 Schema 3、备份格式 2 与既有更新机制不变。
- 本版本经完整 CI 与 Signed Acceptance 验证后，授权同时发布至 GitHub Releases 与 Microsoft Store。
