### 简体中文

UrbanPlanToolbox v1.6.3 主要改进 GitHub 更新系统稳定性。

- 修复更新管理卡片字段显示异常，并移除无意义的“—”占位。
- 修复检查更新过程中布局跳动以及文本与 ProgressRing 重叠的问题。
- 修复多语言 Release Notes 加载，中文和日文界面不再错误显示英文更新说明。
- 改进 GitHub 更新状态管理，增加下载后的验证阶段，并增强状态回退保护。

本版本发布于 GitHub Releases；Microsoft Store 不包含本版本。

### 日本語

UrbanPlanToolbox v1.6.3 では、GitHub 更新システムの安定性を主に改善しました。

- 更新管理カードの項目表示を修正し、意味のない「—」プレースホルダーを削除しました。
- 更新確認中のレイアウト変動と、テキストと ProgressRing の重なりを修正しました。
- 多言語 Release Notes の読み込みを修正し、中国語・日本語 UI に英語の更新内容が表示される問題を解消しました。
- GitHub 更新の状態管理を改善し、ダウンロード後の検証段階と状態後退の保護を追加しました。

このバージョンは GitHub Releases で公開します。Microsoft Store には含まれません。

### English

UrbanPlanToolbox v1.6.3 primarily improves GitHub update-system stability.

- Fixed update-management card fields and removed meaningless dash placeholders.
- Fixed layout shifts during update checks and overlapping text and ProgressRing indicators.
- Fixed localized Release Notes loading so Chinese and Japanese UIs no longer display English notes incorrectly.
- Improved GitHub update-state management with a post-download verifying phase and regression protection against state fallback.

This version is released through GitHub Releases. It is not included in the Microsoft Store.
