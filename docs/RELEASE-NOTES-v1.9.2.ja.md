# UrbanPlanToolbox v1.9.2 専門データライブラリと Data Pack 1.0

- 新しい Figma デザインに合わせ、建築・都市計画法規索引、中日英都市計画用語集、デザインコンセプト辞典を検索リスト、詳細ペイン、独立データソースカードの共通構成へ刷新しました。
- 3 つのライブラリを UrbanPlanToolbox_Data に正式接続し、新画面ではメインリポジトリの旧データファイルを実行時データソースとして使用しません。データ版とアプリ版は独立して更新できます。
- DataPackResolver、DataPackCatalogService、DataPackInstaller を追加し、公式 Catalog の確認、GitHub Release からの取得、ローカル .uptdata の読み込み、前版へのロールバックに対応しました。
- Data Pack 1.0 は有効化前に Pack ID、Schema、最低アプリ版、パス安全性、サイズ、パッケージとペイロードの SHA-256 を検証し、未宣言ファイルやパストラバーサルを拒否します。
- 初回 2026.08.1 は法規索引 221 件、中日英用語 140 件、デザインコンセプト 18 件を対象とし、フィルター、件数、出典表示は実データから生成します。
- データ更新はユーザー操作時のみ行われ、ネットワークが利用できない場合もインストール済みデータをオフラインで利用でき、旧版はロールバック用に保持されます。
