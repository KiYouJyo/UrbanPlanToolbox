# UrbanPlanToolbox v1.9.3 デザインコンセプトDB 第3版

- デザインコンセプトDBを Data Pack 2026.08.3 へ更新し、審査済み68件に41件の canonical コンセプトを追加して計109件としました。
- カテゴリ、適用プロジェクト種別、タグ、事例メモ、出典説明まで中日英3言語を完全対応し、日本語・英語UIで中国語へフォールバックする問題を解消しました。
- 既存の中国語 canonical キーとフィルター互換性を維持したまま、データパックに3言語ラベルカタログを追加しました。
- 旧データパックも読み込み可能ですが、日本語・英語訳がない項目は中国語を誤表示せず空表示にします。2026.08.3へ更新すると完全な翻訳を利用できます。
- 検索対象に3言語のカテゴリ、プロジェクト種別、タグを追加し、表示言語のままコンセプトを検索できるようにしました。
