# UrbanPlanToolbox Roadmap

Current product and channel facts are defined by [project-status.json](project-status.json). Historical changes belong in [CHANGELOG.md](../CHANGELOG.md) and versioned release notes.

## Current stage

UrbanPlanToolbox is in 1.x stabilization and productization. v1.6.8 is a maintenance closeout release: it adds no new professional tool. The GitHub updater is validated and frozen; final Microsoft Store updater E2E remains pending.

## Priorities

1. Maintain the three-language documentation, release-data, and localization contracts.
2. Maintain measured startup, package-size, and dependency baselines.
3. Freeze the Store updater only after a real Store-delivered N → 1.6.8 E2E.

This roadmap does not assign unapproved work a release number or date.
