# UrbanPlanToolbox v1.9.3 Design Concepts Database v3

- Upgrades the Design Concepts database to Data Pack 2026.08.3, adding 41 reviewed canonical concepts to the existing 68 for a total of 109 entries.
- Completes Chinese, Japanese and English localization across categories, applicable project types, tags, case notes and source notes, eliminating Chinese fallback text in Japanese and English UI.
- Adds a trilingual label catalog at the data-pack level while preserving existing canonical Chinese keys for filtering and compatibility.
- Older packs remain readable, but missing Japanese or English content no longer incorrectly falls back to Chinese; updating to 2026.08.3 provides complete content.
- Search now includes localized categories, project types and tags in all three languages so concepts remain searchable in the active UI language.
