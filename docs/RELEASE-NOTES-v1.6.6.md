## 简体中文

UrbanPlanToolbox v1.6.6 主要优化启动体验与窗口状态恢复。

- 优化启动画面与主窗口 Mica 的视觉衔接。
- 快速启动时，启动 Logo 至少完整显示约 0.5 秒；初始化时间更长时会自然延长。
- 优化启动画面的淡出过渡。
- 浅色模式使用黑色 Logo，深色模式使用白色 Logo，并统一两种主题下的尺寸、清晰度和 DPI 表现。
- 新增窗口尺寸和最大化状态记忆，重新启动时恢复上一次正常使用的窗口大小。
- 当显示器工作区变化时，安全调整恢复尺寸，避免窗口超出屏幕。

本版本仅通过 GitHub Releases 发布；Microsoft Store 不在本次发布范围内。

## 日本語

UrbanPlanToolbox v1.6.6 では、起動体験とウィンドウ状態の復元を改善しました。

- 起動画面とメインウィンドウの Mica 表示の視覚的な連続性を改善しました。
- 高速起動時でも起動 Logo を約 0.5 秒以上表示し、初期化に時間がかかる場合は自然に延長します。
- 起動画面のフェードアウトを改善しました。
- ライトテーマでは黒い Logo、ダークテーマでは白い Logo を使用し、サイズ、鮮明さ、DPI 表示を統一しました。
- ウィンドウサイズと最大化状態を記憶し、次回起動時に前回の通常サイズを復元します。
- ディスプレイの作業領域が変わった場合も、画面外に出ないよう安全に復元サイズを調整します。

v1.6.6 は GitHub Releases のみで公開します。Microsoft Store は今回の対象外です。

## English

UrbanPlanToolbox v1.6.6 improves startup presentation and window-state restoration.

- Improved visual continuity between the startup screen and the main-window Mica backdrop.
- Fast launches keep the startup logo visible for at least about 0.5 seconds, while longer initialization naturally extends the display time.
- Refined the startup fade-out transition.
- Light theme uses the black logo and dark theme uses the white logo, with consistent sizing, sharpness, and DPI behavior.
- Added persistence for window size and maximized state so the previous working size is restored on the next launch.
- Restored window geometry is safely constrained when the available display work area changes.

This version is released through GitHub Releases only. Microsoft Store is not part of this release.
