# UrbanPlanToolbox v1.9.0 自由磁贴项目工作台

- 全面重绘设计项目与研究项目页面：顶部保留固定项目概览，下方改为可按项目独立编排的自由磁贴工作台，减少密集表单带来的视觉负担。
- 新增项目级 12 列磁贴布局，可添加、移动、缩放、复制、删除、撤销与恢复默认面板；删除或重置布局不会删除项目正文、文件、灵感或时间节点等源数据。
- 设计项目提供图片展示架、时间节点、项目说明、关联灵感、文件入口、重点策略等面板；研究项目提供研究框架、核心研究问题、结果图表、文献资料、数据与脚本、研究进度等面板。
- 新增响应式工作台：宽窗口保持 12 列自由布局，中等宽度自动映射为 8/6 列，窄窗口切换单列阅读；响应式重排只影响显示，不覆盖已保存的 12 列布局。
- 项目概览、时间节点、工作文件夹和面板设置改为按需编辑或右侧抽屉，归档项目继续保持只读；旧项目首次打开时会自动建立并保存兼容的新工作台布局。
