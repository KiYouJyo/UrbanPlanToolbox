# 规划工具箱（UrbanPlan Toolbox）

版本 `0.1.1`。面向 Windows 的城市规划辅助工具箱，第一版提供“规划指标快速计算器”。

## 功能

- 容积率、建筑密度、绿地率、人口/户均、停车位、公共服务设施指标计算。
- 总、地上、地下建筑面积与停车位分类联动推算及冲突警告。
- 示例数据、结果复制、浅色/深色/跟随系统主题设置。

## 技术与系统要求

C#、.NET 10、WinUI 3、Windows App SDK 和单项目 MSIX。支持 Windows 10 17763+，优先 Windows 11 x64。开发需要 Visual Studio 2026 的 WinUI 工作负载、Windows SDK 10.0.26100.0 和 .NET SDK 10。

## 本地隐私

规划输入仅在本机内存中计算；应用不提供账号、云同步、网络请求、遥测、广告或 AI 接口，也不会上传规划数据。
